Send a file straight to them.

adhal connects two devices directly and moves a file between them, end-to-end encrypted. No account, and no server storing it along the way.

Sharing a file shouldn't mean leaving a copy behind.

Usually: stored

Direct

Most sharing is an upload to someone else's servers. adhal sends device to device, so there's no hosted copy to retain or leak.

Usually: readable

Sealed

Keys are derived on the two devices from the code, and the code is never sent. Anything carrying the traffic sees only ciphertext.

Usually: capped

Unbound

No account, no plan tiers. Pipe a stream of unknown length straight in, and an interrupted transfer resumes where it stopped.

Under the hood.

Built on Holepunch's and , with a small, specified protocol on top. adhal runs no servers of its own.

Discovery
Peers meet on and hole-punch through home routers and carrier-grade . No port forwarding.
Pairing
Five words: a two-word public meeting point and a three-word secret (about 38.8 bits) used as the password for a . Guesses can only be tried live.
Encryption
Every frame after the handshake is sealed with under keys from the PAKE, with frame lengths authenticated.
Integrity
The receiver sees name, size and before accepting. The file is saved only when its digest matches, and never over an existing file.
Fallback
For networks that can't connect directly, an opt-in relay (--relay=<key>) carries the encrypted traffic. It's experimental; the relay sees both IP addresses, never the file.
Protocol
Wire protocol v2, specified and frozen, with a conformance suite. MIT licensed. Read the spec.

Private, not anonymous. Each side sees the other's IP address, as do DHT nodes near the meeting point.

Send a real file

Real drops run in the adhal command-line tool today; desktop and mobile apps are on the way. You need Node.js 24 or later, on macOS or Linux.

  1. 1 · Install, on both machines
    $ npm install --global @ad-hal/cli
  2. 2 · The receiver shows a code
    $ ad-hal-receive --new ~/Downloads
  3. 3 · You send, and type the code at the prompt
    $ ad-hal-send - ./report.pdf
